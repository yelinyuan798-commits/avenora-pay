# 商户自助开通

商户使用已经部署的 Avenora Pay 服务时，无需再安装服务器。访问运营者的网站，注册账户后，在「开始收款」页面完成配置；进度会根据实际账户资源更新，退出后可以继续。

## 选择套餐

首页和套餐页均可进入注册。先选套餐再注册，会保留所选套餐，登录后可以继续购买。免费计划可直接开始配置；付费档位用于增加额度，当前名称、价格与限制以本站套餐页为准。

购买付费套餐会生成一张订阅账单。到收银台选择本站开放的网络与币种，按本单完整金额转账，链上确认后系统自动开通。未付款时可在「套餐与用量」继续支付已有账单，不会因重新进入而重复生成待付账单。浏览器回跳不代表付款成功。

订阅为主动付款续期，没有自动扣款。同档续费增加一个自然月；不同档位需当前套餐及宽限期结束后再购买。平台尚未配置订阅收款时，页面会说明原因，不会显示为已开启真实收费。运营者配置见[平台订阅说明](billing.md)。

## 配置收款

1. 创建一个项目，用来归集一家店铺或一个业务的收款。
2. 选择本站已经配置的收款网络与币种，填写自己控制的钱包的**公开收款地址**。不要提供私钥、助记词或密码。一个地址不能重复绑定到不同项目或商户。
3. 选择业务接入方式：创建支付链接后分享给客户；或在 API 密钥与 Webhook 页面配置商城接入。需要平台自带自动发货时，先创建商品并录入库存，再创建关联该商品的订单，将订单收银台分享给客户。普通收款链接不自动关联商品库存。

普通地址转账模式无需连接钱包。每笔订单的网络、币种、完整应付金额和截止时间以收银台为准；同地址的金额冲突可能产生识别尾数，客户不能省略本单尾数。BNB 新报价最多保留六位小数。

开通页只把有效地址、已配置网络和可用报价计入当前收款状态。行情短暂不可用时，已经保存的地址仍保留，页面会提示等待行情恢复。注册表中列出的网络不代表当前站点全部开放。

## 核对业务流程

「已配置」只表示所需设置存在。正式销售前，应做一笔自己可控制的小额实付，核对订单到账、确认数、交付内容与通知记录。外部商城还需要验证签名通知、重试与幂等发货，不能以填写 Webhook 地址代替联调。

`GET /api/onboarding` 仅返回当前已登录商户的开通状态，不返回平台运营者的地址、节点凭据、API 密钥或库存内容。公开演示与正式账户隔离，演示账单不能开通真实订阅。
